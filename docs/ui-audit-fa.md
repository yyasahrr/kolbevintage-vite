# ممیزی UI/UX — فروشگاه ولور (۲۰۲۶-۱۱-۰۴)

این سند نتیجهٔ پروتکل «UI/UX Audit, Repair & Validation» روی همین مخزن است.
برای هر مورد: شناسه، صفحه/کامپوننت، بُرش عرض، دستهٔ نقص، شدت، ریشه، فایل، اصلاح،
وضعیت اعتبارسنجی.

> **محدودیت ابزار (شفاف):** اجرای واقعی مرورگر در این محیط ممکن نیست — باینری
> Chromium در دسترس نیست و دانلود آن از CDN پلاگ‌این (cdn.playwright.dev) خارج از
> شبکهٔ مجاز سندباکس است (`npx playwright install chromium` → `Download failure`).
> بنابراین «اسکرین‌شات قبل/بعد» و اندازه‌گیری DOM در عرض‌های مختلف انجام نشده است.
> اعتبارسنجی جایگزین: بازبینی استاتیک CSS/JSX + `tsc` (کلاینت و سرور) + `vite build`
> + ۳۹/۳۹ تست Integration + سرویس زندهٔ Vite روی 5173. هرجا «✅ تأییدشده» نوشته
> شده، یعنی از طریق همین سه مسیر تأیید شده، نه از طریق اسکرین‌شات.

## ۳) مواردی که بررسی و «سالم» تشخیص داده شدند

- همهٔ `<img>` ها `alt` دارند (اسکن ۰ مورد).
- فقط یک جدول بدون ظرف اسکرول وجود داشت (UI-06).
- `:focus-visible` سراسری در `index.css` تعریف شده و حذف نشده است.
- زنجیرهٔ z-index فروشگاه (۱۰/۲۰/۳۵/۴۰/۵۰/۵۵/۵۶/۶۰/۶۱/۶۵/۶۶/۶۸/۷۰/۸۰/۹۰) بدون
  تصادم است: هدر ۴۰ < شیت/کشو ۵۵–۶۱ < مودال‌ها ۶۵–۷۰ < توست ۹۰.
- حالت‌های خالی موجود است: سبد خرید، علاقه‌مندی، نتیجهٔ جست‌وجو، فهرست پنل.
- `Escape` در کشوی سبد، شیت منوی موبایل، پنل جزئیات استایل و مودال‌های ادمین هست.

## ۴) اعتبارسنجی (Phase 6)

```
npx tsc --noEmit                        → ۰ خطا (کلاینت)
npx tsc -p server/tsconfig.json --noEmit → ۰ خطا (سرور)
npm run build                            → موفق (dist/index.html ≈ ۲٫۶MB، gzip ۱٫۲MB)
npm test                                 → ۳۹/۳۹ سبز (PostgreSQL واقعی)
curl /api/health                         → 200
```

عرض‌های ۳۲۰/۳۷۵/۳۹۰/۴۳۰/۷۶۸/۱۰۲۴/۱۲۸۰/۱۴۴۰/۱۹۲۰ **با مرورگر تست نشده‌اند**
(دلیل در بالای سند). پیشنهاد: پیش از انتشار، همین سند را با اسکرین‌شات همان ۹ عرض
و «بدون اسکرول افقی» کامل کنید؛ اگر مرورگری در دسترس شد، ابتدا UI-22 و UI-21.

## ۵) ریسک‌های باقی‌مانده

1. تغییر بریک‌پوینت صفحهٔ محصول به `md` روی تبلت‌های باریک (۷۶۸px) ممکن است ستون
   خرید را تنگ کند؛ اگر دیده شد، فقط همان دو کلاس به `lg` برگردد.
2. حذف سطح «گروه محصول» از فروشگاه: لینک‌های قدیمی `?category=` همچنان کار می‌کنند
   (فیلتر در `filterProducts` مانده) اما UI برایشان چیپ ندارد.
3. ضریب تومان (پیش‌فرض ۱۰۰۰) یک نمایش است، نه نرخ واقعی؛ از پنل → تنظیمات فروشگاه
   قابل تغییر است و روی فاکتور/پرداخت سمت سرور اثری ندارد.
