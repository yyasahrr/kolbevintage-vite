# کارت محصول و بوم استایل — وضعیت پیاده‌سازی

- کارت‌های فروشگاه، علاقه‌مندی‌ها، صفحهٔ منتشرشدهٔ استودیو، محصولات مرتبط و کارت‌های استایل از تصویرهای واقعی کاتالوگ استفاده می‌کنند. کارت تعاملی ابتدا عکس اصلی را نشان می‌دهد و با فلش یا سوایپ بین تصاویر گالری (از جمله تصویر hover ثبت‌شده) جابه‌جا می‌شود؛ هاور یا فوکوس عکس اول را عوض نمی‌کند تا اولین کلیک عکسی را رد نکند. فلش‌ها و شمارنده تنها وقتی بیش از یک تصویر موجود باشد نمایش داده می‌شوند؛ کنترل‌ها داخل لینک محصول نیستند. قلب و نشان کارت مستقل از اسلاید و ثابت‌اند. روی تصاویر صفحهٔ جزئیات قلب و برچسب قرار نمی‌گیرد و دکمهٔ علاقه‌مندی کنار خرید باقی می‌ماند. تصویر خراب/حذف‌شده پیام جایگزین دارد.
- بوم شخصی استایل با ماوس، لمس و صفحه‌کلید قابل جابه‌جایی است؛ انتخاب، لایه، تکرار، وارونگی، چرخش تصویر، اندازه، شبکه، پس‌زمینه و بزرگ‌نمایی داخل محدودهٔ پیمایش دارد. تصویر شفاف متناسب با رنگ انتخابی در صورت وجود ترجیح داده می‌شود. خود تصویر (نه کارت، نام یا قیمت) روی بوم است و مرز اندازه و چرخش کنترل می‌شود. حذف همه تأیید می‌خواهد. افزودن ست موجودی و تعدادهای تکراری و سبد فعلی را در نظر می‌گیرد؛ تأیید نهایی موجودی با سرور است.
- بوم و ست‌های ذخیره‌شده در localStorage همین مرورگر هستند، نه حساب کاربر یا پایگاه داده؛ پاک‌کردن دادهٔ مرورگر آنها را حذف می‌کند. خروجی گرفتن به تصویر، اشتراک‌گذاری، undo/redo مستقل بوم و حذف خودکار پس‌زمینه هنوز وجود ندارد؛ بوم پرو مجازی لباس نیست.
- این تغییر جایگزین صفحه‌ساز فروشگاه یا به‌معنی آماده‌بودن تولید نیست؛ وضعیت و موانع صفحه‌ساز و production در `site-builder-plan-fa.md` و `production-readiness-fa.md` ثبت شده‌اند.

## آزمون‌ها

`npm run typecheck`, `npm run build`, `npm run audit`, `npm run test:live-catalog` و `npm run test:browser-store` اجرا شدند. آزمون مرورگری کارت/بوم شامل ترتیب تصاویر و کنترل‌ها، شبکهٔ محصول در شش عرض، محصول تک‌تصویر و بدون تصویر، سوایپ افقی و عمودی، drag ماوس و لمس شبیه‌سازی‌شدهٔ Chromium، کلیدها، zoom زیر و بالای ۱۰۰٪، کنترل‌های تصویر، انتخاب رنگ، موجودی نسخه‌های تکراری، تأیید پاک‌سازی، ذخیره و بازیابی، مرزها در ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ پیکسل، تم neo-brutalism و axe است. آزمون مدیریت تصاویر نیز روی پایگاه موقت موفق بود. دستگاه فیزیکی و مرورگرهای دیگر آزموده نشده‌اند.

آزمون زیر دادهٔ محصول، موجودی و فایل تصویر می‌سازد و حذف نمی‌کند؛ فقط با سرور محلی متصل به پایگاه دورریختنی با نام `kv_canvas_ui_*` و پوشهٔ آپلود موقت اختصاصی (`UPLOADS_DIR` در فرایند سرور) اجرا شود:

```sh
CANVAS_SMOKE_ALLOW_MUTATIONS=1 \
BROWSER_TEST_BASE=http://127.0.0.1:8099 \
BROWSER_TEST_DATABASE_URL=postgresql://USER:PASSWORD@127.0.0.1:55432/kv_canvas_ui_example \
PLAYWRIGHT_CHROMIUM_PATH=/path/to/chromium \
npm run test:browser-card-canvas
```

## چیدمان بوم

در عرض ۷۶۸ پیکسل و بالاتر پنل محصولات سمت راست بوم و امتیاز و خلاصهٔ ست سمت چپ، باز هستند. در عرض موبایل پنل محصولات با دکمه باز می‌شود و خرید و امتیاز زیر بوم همیشه دیده می‌شوند؛ با انتخاب محصول پنل بسته و قطعه انتخاب می‌شود، و Escape پنل را می‌بندد. پس‌زمینهٔ پیش‌فرض بوم سفید با شبکهٔ مربعی است؛ انتخاب پیشین زمینهٔ کاربر حفظ می‌شود و سایر زمینه‌ها همچنان قابل انتخاب‌اند.

## چیدمان کارت‌ها

در شبکه‌های اصلی محصول، موبایل دو ستون و تبلت از ۷۶۸ پیکسل سه ستون دارد. فروشگاه با پنل فیلتر در ۱۲۸۰ پیکسل چهار ستون و در ۱۵۳۶ پیکسل پنج ستون دارد؛ شبکه‌های تمام‌عرض در دسکتاپ چهار تا پنج ستون دارند. تعداد محصولات هر بخش ممکن است کمتر از تعداد ستون‌ها باشد.

## جهت گالری محصول

در گالری جزئیات و روی کارت، «قبلی» سمت راست و «بعدی» سمت چپ است. تصاویر واقعی کارت با انیمیشن اسلایدی جابه‌جا می‌شوند؛ در تنظیم کاهش حرکت، انیمیشن غیرفعال است. روی موبایل سوایپ راست تصویر بعدی و سوایپ چپ تصویر قبلی را نشان می‌دهد. فلش‌ها برای محصولی که فقط یک تصویر واقعی دارد نمایش داده نمی‌شوند؛ برای فعال‌شدن گالری باید تصویر دیگری در مدیریت تصاویر محصول ثبت شود.

## تصویر شفاف محصول برای بوم

در پنل مدیریت، محصول را ویرایش کنید و در «تصاویر محصول» یک فایل PNG یا WebP شامل خود محصول با پس‌زمینهٔ شفاف بارگذاری و نقش «تصویر شفاف برای بوم استایل» و رنگ آن را انتخاب کنید. برای تصویر مشترک همهٔ رنگ‌ها گزینهٔ همه رنگ‌ها را انتخاب کنید. در بوم تصویر مخصوص رنگ انتخابی و سپس تصویر مشترک استفاده می‌شود. اگر تصویری ثبت نشده یا بارگذاری نشود، پیام جایگزین نشان داده می‌شود؛ تصاویر معمولی به‌اشتباه به‌عنوان تصویر بریده‌شده نمایش داده نمی‌شوند.

این قابلیت پس‌زمینه را خودکار حذف نمی‌کند. سرور وجود کانال شفاف و پیکسل‌های شفاف و غیرشفاف را بررسی می‌کند، اما نمی‌تواند تضمین کند که فایل واقعاً فقط شامل محصول است؛ آماده‌سازی صحیح فایل برعهدهٔ فروشگاه است. آپلود فایل واقعی برای نقش بوم لازم است و URL خارجی یا تغییر نقش عکس قبلی به بوم پذیرفته نمی‌شود. تصویر بوم وارد گالری عمومی یا تصویر سبد نمی‌شود. فایل‌های آپلودشده، مثل سایر رسانه‌ها، باید جداگانه پشتیبان‌گیری شوند.

## سینی محصول، راهنمای سایز و دستیار

سینی محصول دارای جست‌وجو، دسته‌بندی و فیلترهای «فقط موجودها» و «تصویر بوم» است. وضعیت تصویر بوم برای رنگ فعلی یا رنگ اولیه نشان داده می‌شود؛ انتخاب دوبارهٔ محصول آن را روی بوم انتخاب می‌کند، نه اینکه نسخه‌ای جدید بسازد. موجودی نمایش‌داده‌شده لحظه‌ای نیست و خرید نهایی در سرور بررسی می‌شود.

تصویر راهنمای اندازه‌گیری یک تصویرسازی تزئینی تولیدشده است و مقیاس یا اندازهٔ بدن واقعی نیست. جدول سایز همچنان فقط داده‌های ثبت‌شدهٔ فروشگاه در دستهٔ محصول را نمایش می‌دهد؛ نبود جدول، اندازه‌های خالی و نامشخص‌بودن مبنای بدن/لباس صریحاً اعلام می‌شوند.

دستیار با شش پرسش و قواعد سادهٔ رنگ، موقعیت، دما، فرم و سلیقه محصولات موجود را مرتب می‌کند؛ هوای آنلاین، تشخیص تناسب یا توصیهٔ خودکار سایز ندارد. سایز اولیه فقط اولین گزینهٔ موجود است و خریدار باید آن را قبل از خرید بررسی کند. شهر و فصل فقط یادداشت هستند. امکان رد کردن حتی بخش بی‌محصول، بازگشت، ادامه پس از جابه‌جایی بین بوم و دستیار، و شروع مجدد وجود دارد. با ویرایش انتخاب قبلی، انتخاب‌های وابستهٔ بعدی پاک می‌شوند. پیش از جایگزینی بوم تأیید گرفته می‌شود و اگر موجودی انتخاب‌ها دیگر قابل تأیید نباشد انتقال انجام نمی‌شود. پاسخ‌های دستیار در حافظهٔ همان صفحه‌اند و با تازه‌سازی از بین می‌روند.

برای بررسی رابط از سرور و دادهٔ محلی استفاده کنید:

```sh
BROWSER_TEST_BASE=http://127.0.0.1:8099 \
PLAYWRIGHT_CHROMIUM_PATH=/path/to/chromium \
npm run test:browser-style-wizard
```
