# کارت محصول و بوم استایل — وضعیت پیاده‌سازی

- کارت‌های فروشگاه، علاقه‌مندی‌ها، صفحهٔ منتشرشدهٔ استودیو، محصولات مرتبط و کارت‌های استایل از تصویرهای واقعی کاتالوگ استفاده می‌کنند. عکس نقش hover در هاور یا فوکوس نمایش داده می‌شود؛ در نبود آن، اولین عکس بعدی به‌کار می‌رود. فلش‌ها، شمارنده و سوایپ تنها وقتی بیش از یک تصویر موجود باشد نمایش داده می‌شوند؛ کنترل‌ها داخل لینک محصول نیستند. تصویر خراب/حذف‌شده پیام جایگزین دارد.
- بوم شخصی استایل با ماوس، لمس و صفحه‌کلید قابل جابه‌جایی است؛ انتخاب، لایه، تکرار، وارونگی، چرخش تصویر، اندازه، شبکه، پس‌زمینه و بزرگ‌نمایی داخل محدودهٔ پیمایش دارد. عکس رنگ انتخابی در صورت وجود ترجیح داده می‌شود. چرخش در قاب عکس بریده می‌شود و اندازهٔ ظاهری در مرز بوم محدود است. حذف همه تأیید می‌خواهد. افزودن ست موجودی و تعدادهای تکراری و سبد فعلی را در نظر می‌گیرد؛ تأیید نهایی موجودی با سرور است.
- بوم و ست‌های ذخیره‌شده در localStorage همین مرورگر هستند، نه حساب کاربر یا پایگاه داده؛ پاک‌کردن دادهٔ مرورگر آنها را حذف می‌کند. خروجی گرفتن به تصویر، اشتراک‌گذاری، undo/redo مستقل بوم و حذف پس‌زمینهٔ تصویر هنوز وجود ندارد. بوم یک moodboard با قاب عکس است، نه پرو مجازی لباس.
- این تغییر جایگزین صفحه‌ساز فروشگاه یا به‌معنی آماده‌بودن تولید نیست؛ وضعیت و موانع صفحه‌ساز و production در `site-builder-plan-fa.md` و `production-readiness-fa.md` ثبت شده‌اند.

## آزمون‌ها

`npm run typecheck`, `npm run build`, `npm run audit`, `npm run test:live-catalog` و `npm run test:browser-store` اجرا شدند. آزمون مرورگری کارت/بوم شامل تصویر hover و کنترل‌ها، محصول تک‌تصویر و بدون تصویر، سوایپ افقی و عمودی، drag ماوس و لمس شبیه‌سازی‌شدهٔ Chromium، کلیدها، zoom زیر و بالای ۱۰۰٪، کنترل‌های تصویر، انتخاب رنگ، موجودی نسخه‌های تکراری، تأیید پاک‌سازی، ذخیره و بازیابی، مرزها در ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ پیکسل، تم neo-brutalism و axe است. آزمون مدیریت تصاویر نیز روی پایگاه موقت موفق بود. دستگاه فیزیکی و مرورگرهای دیگر آزموده نشده‌اند.

آزمون زیر دادهٔ محصول و موجودی می‌سازد و حذف نمی‌کند؛ فقط با سرور محلی متصل به پایگاه دورریختنی با نام `kv_canvas_ui_*` اجرا شود:

```sh
CANVAS_SMOKE_ALLOW_MUTATIONS=1 \
BROWSER_TEST_BASE=http://127.0.0.1:8099 \
BROWSER_TEST_DATABASE_URL=postgresql://USER:PASSWORD@127.0.0.1:55432/kv_canvas_ui_example \
PLAYWRIGHT_CHROMIUM_PATH=/path/to/chromium \
npm run test:browser-card-canvas
```

## چیدمان بوم

در عرض ۹۰۰ پیکسل و بالاتر پنل محصولات سمت راست بوم و امتیاز و خلاصهٔ ست سمت چپ هستند. در عرض‌های کوچک‌تر دکمه‌های دو سمت بوم پنل‌های کناری را باز می‌کنند؛ با انتخاب محصول پنل بسته و قطعه انتخاب می‌شود، و Escape پنل را می‌بندد. پس‌زمینهٔ پیش‌فرض بوم سفید با شبکهٔ مربعی است؛ انتخاب پیشین زمینهٔ کاربر حفظ می‌شود و سایر زمینه‌ها همچنان قابل انتخاب‌اند.
